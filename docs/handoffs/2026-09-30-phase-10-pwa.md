## The service worker is deliberately thin

The data is in IndexedDB, not behind a network call, so there is nothing to
sync and nothing to intercept for note reads. The worker exists for one reason:
**the user must still reach their notes with no network.** That matters more
here than in a normal app, because browser storage is evictable and someone
opening the app offline is exactly the person who must not find it broken.

- navigations: network first, cached shell on failure
- `/_next/static/`: cache first
- everything else: passthrough. A mutation is never cached or replayed.

Registered in **production only** — caching the dev bundle makes hot reload
behave unpredictably. Failure to register is swallowed, because a missing
service worker must never break the app.

## Focus mode persists

`focusMode` is in `AppSettings` (schema note: adding a settings key is additive
and needs no migration). It is read on mount, not synced via an effect, and
written from the toggle callback.

The floating exit button is only rendered while focus mode is on, so there is
always a way out — it disappears from the header it hides.

## Command palette

Every entry is a shortcut to something that already exists elsewhere; it is not
a second implementation. Search is over recent notes, notebooks, tags, plus
create/navigate/theme actions. ⌘K or Ctrl-K, handled at the document level so
it works from any pane.
